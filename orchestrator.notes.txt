  ---
  📋 CRITICAL SUCCESS REQUIREMENTS

  1. Task Structure (Non-negotiable)

  AgentTask(
      task_id="unique_identifier",        # MUST be unique across all tasks
      task_type="descriptive_category",   # For logging/organization
      prompt="Clear, specific instructions", # The actual work description
      dependencies=["list_of_task_ids"],  # Tasks that must complete first
      context={"phase": "info"}           # Optional metadata
  )

  2. Dependency Rules

  - ✅ Sequential: task_2 depends on task_1 → executes in order
  - ✅ Parallel: Multiple tasks depend on task_1 → all execute simultaneously after task_1
  - ✅ Aggregation: final_task depends on multiple tasks → waits for all to complete
  - ❌ Never: Circular dependencies (A → B → A)

  ---
  🏗️ PROVEN WORKFLOW PATTERNS

  Pattern 1: Linear Pipeline

  setup → data_prep → analysis → report
  Use when: Each step builds directly on the previous

  Pattern 2: Fan-Out/Fan-In

           ┌→ worker_1 ┐
  setup → data_prep → worker_2 → aggregate → final_report
           └→ worker_3 ┘
  Use when: Independent parallel processing needed

  Pattern 3: Multi-Stage Processing

  stage_1 → [parallel_workers] → stage_2 → [more_workers] → final
  Use when: Complex multi-phase workflows

● An agent needs to understand:

  Core Concepts:
  - Each agent runs as a separate claude -p CLI process
  - Tasks are AgentTask objects with prompts and dependencies
  - GenericOrchestrator manages parallel execution and token distribution

  Essential Files:
  - src/generic_orchestrator.py - Main orchestration class
  - Your execution script - Defines tasks and runs orchestrator
  - Debug logs in output_dir/logs/orchestrator_*.log

  Basic Pattern:
  1. Import GenericOrchestrator and AgentTask
  2. Define tasks with clear prompts and dependencies
  3. Create orchestrator with output directory and parallelism settings
  4. Run with await orchestrator.run(task_generator=your_tasks)

  Key Success Factors:
  - Clear task prompts with missions, requirements, deliverables
  - Reasonable parallelism (5-8 concurrent agents)
  - Proper error handling and debug log checking
  - Timestamped output directories

  I've created a comprehensive guide at .claude/knowledge/guides/orchestrator_guide.md with examples, patterns, and troubleshooting.
