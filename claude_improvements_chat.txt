● How Task Tool & Agent Profiles Work

  Key Concepts:

  1. Agent Profiles (.claude/agents/)
  - Local configuration files defining behavior for SDLC phases
  - NOT directly used by Task tool
  - Loaded with Read(".claude/agents/sdlc-[phase].md")
  - Define mindset, objectives, workflow for human Claude

  2. Task Tool subagent_type
  - System-defined agent types (built into Claude Code)
  - Examples: development-specialist, qa-testing-guru, test-remediation-specialist
  - These are NOT the same as your local .claude/agents/ files
  - Full list in Task tool description

  1. Single Task calls - They call Task once instead of multiple times
