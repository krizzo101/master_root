  Go with PostgreSQL + Neo4j Hybrid Architecture

  Why NOT Neo4j for everything:

  Neo4j struggles with:
  - Time-series data - Chat logs are inherently temporal, PostgreSQL + TimescaleDB is optimized for this
  - High-volume raw data - At scale (millions of chat messages), graph databases get expensive
  - Aggregations - "Count messages per day" is trivial in SQL, cumbersome in Cypher
  - Tabular reporting - Dashboards expect SQL-like queries

  Neo4j excels at:
  - Relationship traversal - "What caused this error?"
  - Pattern detection - "Find similar correlation patterns"
  - Knowledge graph - Already working well for your knowledge base
  - Impact analysis - "What depends on this?"

  Recommended Architecture:

  ┌─────────────────────────────────────────┐
  │         MCP API Layer (FastMCP)         │
  ├─────────────────────────────────────────┤
  │       Unified Query Engine              │
  │   (Queries both DBs as needed)          │
  ├─────────────────────────────────────────┤
  │         PostgreSQL          │   Neo4j   │
  ├─────────────────────────────┼───────────┤
  │ • Chat logs (time-series)   │ • Knowledge│
  │ • .proj-intel (JSONB)       │ • Relations│
  │ • Errors/logs               │ • Patterns │
  │ • Metrics                   │ • Causality│
  │ • Full-text search          │ • Impact   │
  │ • Aggregations              │ • Graph    │
  └─────────────────────────────┴───────────┘

  1. Raw data → PostgreSQL (source of truth)
  2. Extract relationships → Neo4j (derived intelligence)

    Data Flow:

    class ViewManager:
        def render_view(self, view_name: str, overlays: List[str] = None):
            # Get base view data
            view = self.views[view_name]
            data = view.collect_data()

            # Apply overlays
            if overlays:
                for overlay_name in overlays:
                    overlay = self.overlays[overlay_name]
                    data = overlay.enhance(data)

            # Render based on output format
            if self.output_format == "terminal":
                return self.render_terminal(data)
            elif self.output_format == "web":
                return self.render_html(data)
            elif self.output_format == "json":
                return self.render_json(data)
