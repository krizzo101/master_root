# Python Async Patterns Research Summary

## Core Concepts

### 1. async/await Fundamentals
- **async def**: Defines a coroutine function that can be awaited
- **await**: Suspends execution and yields control back to event loop
- **asyncio.run()**: Entry point for async programs (Python 3.7+)
- **Event Loop**: Central executor managing async tasks and I/O operations

### 2. Task Management Patterns

#### Concurrent Execution
```python
# Using asyncio.gather() for parallel execution
results = await asyncio.gather(
    coroutine1(),
    coroutine2(),
    coroutine3()
)

# Using asyncio.create_task() for fire-and-forget
task1 = asyncio.create_task(coroutine1())
task2 = asyncio.create_task(coroutine2())
result1 = await task1
result2 = await task2
```

#### Task Groups (Python 3.11+)
```python
async with asyncio.TaskGroup() as tg:
    task1 = tg.create_task(coroutine1())
    task2 = tg.create_task(coroutine2())
# All tasks complete or exception propagates
```

### 3. Concurrency Control Patterns

#### Semaphore Pattern
- Limits number of concurrent operations
- Essential for rate limiting and resource management
```python
semaphore = asyncio.Semaphore(3)  # Max 3 concurrent operations

async def limited_operation():
    async with semaphore:
        # Protected code block
        await expensive_operation()
```

#### Queue Pattern
- Producer-consumer pattern for task distribution
```python
queue = asyncio.Queue(maxsize=100)

# Producer
await queue.put(item)

# Consumer
item = await queue.get()
queue.task_done()
```

### 4. Error Handling Patterns

#### Exception Groups
- Handle multiple exceptions from concurrent tasks
```python
try:
    async with asyncio.TaskGroup() as tg:
        # Multiple tasks
except* ValueError as eg:
    # Handle specific exception group
```

#### Timeout Pattern
```python
try:
    result = await asyncio.wait_for(
        long_running_task(),
        timeout=5.0
    )
except asyncio.TimeoutError:
    # Handle timeout
```

### 5. I/O Patterns

#### Async Context Managers
```python
class AsyncResource:
    async def __aenter__(self):
        await self.acquire()
        return self

    async def __aexit__(self, exc_type, exc_val, exc_tb):
        await self.release()

async with AsyncResource() as resource:
    await resource.use()
```

#### Async Iterators
```python
class AsyncDataStream:
    async def __aiter__(self):
        return self

    async def __anext__(self):
        data = await self.fetch_next()
        if not data:
            raise StopAsyncIteration
        return data

async for item in AsyncDataStream():
    process(item)
```

### 6. Performance Patterns

#### Batching Pattern
- Group operations to reduce overhead
```python
async def batch_processor(items, batch_size=10):
    for i in range(0, len(items), batch_size):
        batch = items[i:i + batch_size]
        tasks = [process_item(item) for item in batch]
        await asyncio.gather(*tasks)
```

#### Connection Pooling
- Reuse connections for efficiency
```python
class ConnectionPool:
    def __init__(self, size=10):
        self._queue = asyncio.Queue(size)
        for _ in range(size):
            self._queue.put_nowait(self._create_connection())

    async def acquire(self):
        return await self._queue.get()

    async def release(self, conn):
        await self._queue.put(conn)
```

### 7. Synchronization Patterns

#### Lock Pattern
```python
lock = asyncio.Lock()

async def critical_section():
    async with lock:
        # Only one coroutine can execute this at a time
        await shared_resource_operation()
```

#### Event Pattern
```python
event = asyncio.Event()

# Waiter
await event.wait()

# Signaler
event.set()
```

### 8. Best Practices

1. **Avoid Blocking Operations**
   - Use `asyncio.to_thread()` for CPU-bound tasks
   - Never use blocking I/O in async functions

2. **Proper Task Cancellation**
   - Handle CancelledError appropriately
   - Use try/finally for cleanup

3. **Resource Management**
   - Always use async context managers
   - Ensure proper cleanup in __aexit__

4. **Debugging Tips**
   - Use `asyncio.create_task()` with name parameter
   - Enable asyncio debug mode: `asyncio.run(main(), debug=True)`
   - Use `asyncio.current_task()` for introspection

5. **Performance Considerations**
   - Batch operations when possible
   - Use semaphores to prevent resource exhaustion
   - Profile with `asyncio.create_task()` vs `await` directly

### 9. Common Anti-Patterns to Avoid

1. **Forgetting await**: Coroutines without await don't execute
2. **Blocking the event loop**: Using time.sleep() instead of asyncio.sleep()
3. **Creating tasks without awaiting**: Memory leaks from unawaited tasks
4. **Mixing sync and async inappropriately**: Use asyncio.to_thread() for sync code
5. **Not handling cancellation**: Leads to resource leaks

### 10. Real-World Application Patterns

#### Web Scraping with Rate Limiting
```python
async def scrape_with_limit(urls, max_concurrent=5):
    semaphore = asyncio.Semaphore(max_concurrent)

    async def fetch_url(session, url):
        async with semaphore:
            async with session.get(url) as response:
                return await response.text()

    async with aiohttp.ClientSession() as session:
        tasks = [fetch_url(session, url) for url in urls]
        return await asyncio.gather(*tasks)
```

#### Database Connection Pool
```python
class AsyncDBPool:
    def __init__(self, dsn, min_size=10, max_size=20):
        self.pool = None
        self.dsn = dsn
        self.min_size = min_size
        self.max_size = max_size

    async def init(self):
        self.pool = await asyncpg.create_pool(
            self.dsn,
            min_size=self.min_size,
            max_size=self.max_size
        )

    async def execute(self, query, *args):
        async with self.pool.acquire() as conn:
            return await conn.fetch(query, *args)
```

#### Message Processing Pipeline
```python
async def message_pipeline(input_queue, output_queue, processor):
    while True:
        message = await input_queue.get()
        if message is None:  # Sentinel
            break

        try:
            result = await processor(message)
            await output_queue.put(result)
        except Exception as e:
            # Handle error
            pass
        finally:
            input_queue.task_done()
```

## Summary

Python's asyncio provides powerful patterns for concurrent programming:
- Use `gather()` and `TaskGroup()` for parallel execution
- Apply semaphores for rate limiting and resource management
- Implement proper error handling with timeouts and exception groups
- Leverage async context managers and iterators for clean code
- Always avoid blocking the event loop
- Profile and monitor async code performance

The key to effective async programming is understanding when to use concurrency (I/O-bound tasks) and properly managing shared resources and task lifecycles.
