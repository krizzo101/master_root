● EXACTLY WHAT PHASE 2 DOES AND HOW

  1. THE CORE MECHANISM

  Phase 2 spawns 5 REAL Claude Code processes simultaneously using subprocess. Each one:
  - Gets its own API token (from pool of 15)
  - Gets its own git worktree (isolated workspace)
  - Receives a specific task via claude --dangerously-skip-permissions -p @task.txt
  - Runs completely independently in parallel

  2. THE EXECUTION FLOW

  # Simplified view of what happens:
  async def execute_phase_2():
      # 1. Initialize resources
      token_pool = TokenPool()  # 15 tokens available
      worktree_manager = WorktreeManager()  # Creates isolated git branches

      # 2. Define 5 tasks (each builds one component)
      tasks = [messaging, registry, specialized, monitoring, integration]

      # 3. Launch 5 Claude processes AT THE SAME TIME
      for task in tasks:
          token = token_pool.acquire()  # Get unique token
          worktree = worktree_manager.create(task_id)  # Create isolated workspace

          # Spawn REAL Claude process
          process = subprocess.create_subprocess_exec(
              "claude", "--dangerously-skip-permissions", "-p", f"@{task_file}",
              env={"CLAUDE_CODE_TOKEN": token},
              cwd=worktree
          )

      # 4. Wait for all to complete
      results = await asyncio.gather(*all_processes)
